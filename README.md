# App

Write your solution in `main.py`. The `listings` data is already defined at the top of the file.

---

## 🚀 How to Run

```bash
./run.sh
```

---

## 🧪 Run Tests

Unit tests are located in `test_sample.py`. Add your own cases there to check your work.

```bash
./run_unittests.sh
```

---

## 🗂️ Project Structure

```
├── main.py             # Write your solution here
├── test_sample.py      # Unit tests
├── run.sh              # Runs your solution
├── run_unittests.sh    # Runs all unit tests
└── README.md           # This file
```
